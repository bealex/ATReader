# 2026-09-16

The Reading shelf now stands by when a writer's books last changed. It used to stand by when this
device last saw the reader in one of them.

## Why the read-time order went

A card's own contents already stood by update time: the runs on it, the loose books after them, and
every row inside a run. Only the cards themselves stood by read time, so the shelf disagreed with
itself from the card down, and a run that grew a chapter last night sat wherever the reader last
happened to leave its author.

Read time also moved under the reader. Opening a book writes a position as soon as a chapter lands,
which lifted that writer to the top while the opening zoom was still running. Update time doesn't
move for reading, so the shelf holds still.

## What came out with it

`AuthorShelf.lastRead`, the library model's `readingTimes` cache and `SQLiteBookStore.readingTimes()`
existed for that one comparator and went with it. Positions are still written to
`reading_position.updated_at` and read one book at a time; nothing reads them in bulk now.

The cards are still refolded mid-zoom, since writing a position changes the store they are built
from, so the stand-in that carries a book through the transition is still needed. What no longer
happens is the cards changing places underneath it.
